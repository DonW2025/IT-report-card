The First 90 Days' toolkit for IT Directors. A 50-point weighted maturity model that audits SME tech debt and generates a professional, link-verified implementation plan.
# IT Discovery & Oversight Audit (50-Point)

## 📌 Overview
This tool is designed for IT Directors and oversight leaders stepping into a new SME environment (<500 employees). It provides a structured "lay of the land" assessment to identify technical debt, security gaps, and business misalignments.

## 🚀 Key Features
- **50-Point Weighted Scoring:** Based on professional SME maturity benchmarks.
- **Context-Aware:** Toggles between In-house/Outsourced models and US/EU regulatory regions.
- **Plain English:** Translates technical jargon into business-impact language for executive reporting.
- **Automated Action Plan:** Generates a professional, printable remediation roadmap including:
  - **Who:** The responsible party.
  - **What:** The specific strategic goal.
  - **When:** Priority-based timelines.
  - **How:** Specific tactical steps and verified industry links.

## 🛠 Tech Stack
- **HTML5/JavaScript** (Single-file application)
- **Tailwind CSS** (Modern styling)
- **Lucide-React** (Iconography)

## 📂 How to Use
1. Clone the repository.
2. Open `index.html` in any modern web browser.
3. Select your **Development Model** and **Compliance Region** at the top.
4. Score each of the 50 criteria from **1 (Chaos)** to **10 (Optimized)**.
5. Click **"Get Action Plan"** to generate your executive remediation report.
